# Icons

ไอคอนในโฟลเดอร์นี้มาจากชุดไอคอนของ LibreOffice
(`icon-themes/<ชุด>_svg/cmd/` ใน https://github.com/LibreOffice/core)

| โฟลเดอร์ | ชุดไอคอน | สัญญาอนุญาต (ตามไฟล์ใน icon-themes/<ชุด>/) |
|---|---|---|
| `icons/` | Colibre | ตรวจสอบใน `icon-themes/colibre/` |
| `icons/breeze/` | Breeze (KDE Visual Design Group) | ดู `icon-themes/breeze/COPYING` |
| `icons/sifr/` | Sifr | CC BY-SA 3.0 (ผู้สร้างตามไฟล์ AUTHORS) |
| `icons/elementary/` | Elementary | ตรวจสอบใน `icon-themes/elementary/` |
| `icons/sukapura/` | Sukapura | Mozilla Public License 2.0 |

หมายเหตุ: ชุด Sifr และ Elementary ไม่มีไฟล์ `lc_charmapcontrol.svg` โดยตรง
LibreOffice ลิงก์ไปที่ `lc_insertsymbol.svg` (ดู `links.txt`) จึงบันทึกไฟล์นั้นในชื่อ `lc_charmapcontrol.svg`

`lc_keyboard.svg` (ทุกชุด) ไม่ได้มาจาก LibreOffice เพราะไม่มีไอคอนคีย์บอร์ดในชุดใดเลย
วาดขึ้นใหม่สำหรับโปรเจกต์นี้ โดยเลียนแบบสไตล์ สี และขนาด 24×24 ของแต่ละชุด

กรุณาตรวจสอบเงื่อนไขสัญญาอนุญาตของแต่ละชุดไอคอน และใส่เครดิตตามที่กำหนด
