สั่ง Claude ทำเกมแมวส้ม 🐾

ชุดพรอมต์ทีละขั้น ใช้ได้กับแผนฟรี · กดคัดลอกแล้ววางในแชต Claude

🧺 ก่อนเริ่ม

เปิด claude.ai หรือแอป Claude แล้วสมัครฟรี จากนั้นเริ่ม แชตใหม่ หนึ่งแชต ให้ Claude สร้างเกมเป็น Artifact (หน้าเว็บเล่นได้ในแชต) ไม่ต้องติดตั้งหรือเขียนโค้ดเอง

วิธีใช้: ส่งพรอมต์ทีละข้อ รอให้เกมรันและลองเล่นก่อน แล้วค่อยส่งข้อถัดไป ถ้าแก้ไม่ถูกใจให้พิมพ์สิ่งที่อยากแก้ต่อเลย

1แมวส้มและการเคลื่อนไหว

ช่วยสร้างเกมแนวเกมบอยเป็นไฟล์ HTML ไฟล์เดียว เล่นได้ในเบราว์เซอร์ หน้าจอ canvas 160x144 พิกเซล ขยายแบบพิกเซลคม มีแมวส้มกลมน่ารักเป็นพิกเซลอาร์ต 16x16 วาดจากโค้ดเอง ไม่ใช้ไฟล์รูป เดินซ้ายขวาด้วยปุ่มลูกศร กระโดดด้วย Space มีท่ายืน เดิน กระโดด และกะพริบตา

2ฉากยาว บันได หลุม และเส้นชัย

เพิ่มฉากยาว 1,000 พิกเซลที่กล้องเลื่อนตามแมว มีภูเขา ต้นไม้ พุ่มไม้ ก้อนเมฆ (ภูเขากับเมฆเลื่อนช้ากว่าเพื่อให้ดูมีมิติ) พื้นมีทั้งทางตรง บันได (ขั้นละ 8 พิกเซล) และหลุม มีก้อนหินวางขวางทาง ชนแล้วเสียพลัง มีหัวใจ 3 ดวงที่มุมจอ ปลายทางเป็นแมวคู่รัก ถ้าเดินไปถึงให้มีหัวใจขึ้นเต็มจอพร้อมข้อความ YOU WIN ถ้าพลังหมดขึ้น GAME OVER แล้วกดเล่นใหม่ได้

เพิ่มศัตรูน่ารัก นก หนู สุนัข ชนิดละ 3 สี เป็นสไปรต์ 16x16 มี 2 เฟรมขยับ หนูกับสุนัขเดินไปมาบนพื้น นกบินลอยขึ้นลง วางกระจายในด่าน ชนจากข้างเสียพลัง แต่กระโดดเหยียบหัวได้ ศัตรูจะแบนแล้วหายไป

4สี 16-bit และเพลง chiptune 🎵

เปลี่ยนภาพทั้งเกมเป็นสีแบบ 16-bit ท้องฟ้าไล่เฉดสี ภูเขา 2 ชั้นมียอดหิมะ พื้นหญ้ามีเงา แล้วเพิ่มเพลง chiptune น่ารักๆ วนซ้ำด้วย Web Audio (คลื่นสี่เหลี่ยมเป็นเมโลดี้ คลื่นสามเหลี่ยมเป็นเบส) ไม่ใช้ไฟล์เสียง พร้อมเสียงกระโดด เสียงโดนชน เสียงเหยียบศัตรู และเสียงชนะ
เบราว์เซอร์จะเริ่มเล่นเสียงได้หลังจากกดปุ่มหรือแตะหน้าจอครั้งแรกเท่านั้น เป็นเรื่องปกติ

5ปุ่มแบบเกมบอย

ทำปุ่มบนหน้าจอให้เหมือนเกมบอย D-pad กากบาทสีดำ ปุ่ม B กับ A สีแดงเข้มเรียงเฉียง Select กับ Start เป็นเม็ดยาวเอียง ใช้ได้ทั้งแตะบนมือถือและคีย์บอร์ด ไม่ต้องมีกรอบตัวเครื่อง เหลือแค่ปุ่ม Select ให้เปิดปิดเสียง Start ให้เริ่มเกมใหม่

6เจอบั๊ก? สั่งแก้แบบประหยัด

ระบุอาการให้ชัด และขอให้แก้เฉพาะจุด เพื่อไม่ให้ Claude เขียนทั้งไฟล์ใหม่ (กินโควตา)

แมวตกทะลุพื้นตอนเดินขึ้นบันได ช่วยหาสาเหตุและแก้เฉพาะส่วนที่เกี่ยวข้อง บอกด้วยว่าแก้บรรทัดไหน ไม่ต้องเขียนไฟล์ใหม่ทั้งหมด

⏳ ข้อจำกัดของแผนฟรี

  • โควตาเป็นรอบ: รีเซ็ตทุก 5 ชั่วโมงนับจากข้อความแรกของรอบ ถ้าเต็มจะมีแจ้งเตือน ต้องรอหรืออัปเกรด
  • ไม่มีตัวเลขตายตัว: จำนวนข้อความต่อรอบขึ้นกับความยาวของแชต ฟีเจอร์ที่ใช้ และช่วงเวลาที่คนใช้เยอะ (Anthropic ไม่ประกาศตัวเลข เว็บภายนอกบางแห่งเคยประมาณราว 40 ข้อความสั้นๆ ต่อรอบ ซึ่งไม่ใช่ตัวเลขทางการ)
  • โมเดล: ใช้ระดับ Sonnet และ Haiku ได้ แต่ไม่มี Opus และโมเดลรุ่นบนสุด
  • ไม่มี Claude Code และเครื่องมือเสริมบางอย่าง เช่น Claude in Chrome ซื้อเครดิตเพิ่มเพื่อใช้ต่อก็ไม่ได้
  • แชตยาวเกินไปจะเต็ม: เกมทั้งไฟล์มีโค้ดหลายร้อยบรรทัด ถ้าแก้หลายรอบแชตจะยาวมาก ควรเริ่มแชตใหม่แล้ววางโค้ดล่าสุดต่อ
  • งานใหญ่กินโควตา: ขั้นที่ 2 และ 4 ใช้โควตาเยอะที่สุด อาจต้องทำครึ่งหนึ่งในรอบนี้ อีกครึ่งในรอบถัดไป
✨ ที่ใช้ได้ในแผนฟรี: ค้นเว็บ ความจำข้ามแชต Projects และ Artifacts (หน้าเกมเล่นได้และแชร์ลิงก์) ตรวจข้อมูลเมื่อ 16 พ.ย. 2026 รายละเอียดเปลี่ยนได้ ดูล่าสุดที่หน้าราคาของ Claude และศูนย์ช่วยเหลือ

💡 เคล็ดลับประหยัดโควตา

  • ส่งพรอมต์ทีละขั้นตามลำดับ อย่ารวมทุกอย่างในข้อความเดียว
  • ขอให้ "แก้เฉพาะส่วน" แทนการเขียนทั้งไฟล์ใหม่
  • บอกรายละเอียดตั้งแต่แรก (ขนาด สี จำนวน) จะได้ไม่ต้องแก้ซ้ำ
  • คัดลอกโค้ดเกมที่ใช้ได้แล้วเก็บไว้ ถ้าแชตเต็มหรือโควตาหมดจะไม่เสียงาน
  • โควตาเต็มก็พักก่อน รอ 5 ชั่วโมงแล้วค่อยทำต่อ
